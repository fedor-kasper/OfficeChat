# OfficeChat

Локальный чат для офиса без сервера. Программа работает в фоне (в трее),
а новые сообщения всплывают в правом нижнем углу поверх всех окон.

## Возможности

- Компьютеры находят друг друга сами (UDP broadcast в локальной сети)
- Личные сообщения, групповые чаты и рассылка «Всем» (раскладывается по личным перепискам).
  Группу создаёт кнопка «＋ Группа»; добавлять людей и переименовывать может любой участник, выйти — каждый сам
- Ответ с цитатой, правка и удаление своих сообщений у всех (правый клик по сообщению;
  стрелка вверх в пустом поле — исправить последнее), «печатает…»
- Список переписок упорядочен по последнему сообщению (новые вверху); нужные можно закрепить
  наверху (правый клик → «📌 Закрепить»)
- Очередь для тех, кто не в сети: сообщение уйдёт, когда компьютер появится; отправку можно отменить.
  Текст и изображения до 5 МБ (в том числе в группах) берут на хранение включённые компьютеры коллег
  и передают адресату, когда он появится, — даже если ваш к тому времени выключен; «Доставлено»
  вернётся к вам тем же путём. Файлы ждут, пока вы и адресат окажетесь в сети одновременно
- Доска напоминаний (важность 1–5, отложить, повтор, участники). Напоминание для того, кто не в сети,
  берут на хранение включённые компьютеры коллег и передают ему, когда он появится, — даже если
  автор к тому времени выключил компьютер (так же передаются удаление и отметка «выполнено»)
- Отметки «Доставлено» и «Прочитано» (в группе — «Прочитали 2 из 3»)
- Изображения (до 20 МБ): кнопка 📎, перетаскивание файлов в окно, вставка Ctrl+V
  (скриншоты и скопированные файлы); превью в ленте, просмотр, «Сохранить как…», копирование
- Файлы любого типа (до 1 ГБ) — так же: 📎, перетаскивание, Ctrl+V. Передаются потоком с прогрессом,
  в ленте — «Открыть», «Сохранить как…», «Показать в папке»
- Стикеры: кнопка 😊 рядом с 📎. Встроены пять наборов (эмоции, жесты, офис, животные, праздник и еда),
  можно добавить свой набор из папки с картинками («＋»), а понравившийся полученный стикер —
  сохранить в «Мои стикеры» (правый клик). Стикер уходит картинкой, поэтому его видят все, даже без набора
- Всплывающие уведомления с быстрым ответом; уведомления можно выключить для отдельной переписки
- Работа в трее (значок показывает число непрочитанных и мигает), автозапуск вместе с Windows
- Обновление по сети: программа сама берёт новую версию у коллеги и перезапускается, пока свёрнута в трей
  (см. «Обновление по сети» ниже)
- Вся история переписки хранится локально
- Мини-игры с собеседником — крестики-нолики, шашки (русские правила) и морской бой:
  приглашение, принять/отклонить, поле прямо в переписке (панель справа), итог записывается в историю

## Режим «Касса»

«Настройки ▾ → Режим «Касса»…» — слева от переписок появляется список поставщиков с балансом
(окно становится шире). Поставщиков добавляют вручную («＋ Поставщик»). По каждому:

- **Поставка** — сколько по накладной и сколько выдали водителю (кнопки «Округлить до 10/50/100»).
  Разница ложится на баланс поставщика: по накладной 672,34 ₽, выдали 700 ₽ — на балансе +27,66 ₽.
  Если выдали меньше — разница списывается с баланса;
- **Возврат товара** — сумма прибавляется к балансу (эти деньги поставщик должен нам);
- **Погашение** — поставщик вернул деньги с баланса или учёл их в накладной — сумма списывается.

Баланс поставщика — сколько он нам должен; вверху — сумма по всем. В истории каждая запись с датой,
кто и на каком компьютере её сделал и баланс после неё. Записи не удаляются и не правятся: ошибку
исправляют «Отменить…» с причиной — запись остаётся зачёркнутой, с тем, кто и когда отменил.

Несколько компьютеров кассы ведут общий журнал **без сервера**: у кого в настройках один и тот же
**код кассы**, те находят друг друга в локальной сети (UDP 45683) и обмениваются недостающими записями.
Можно работать и без сети — записи догонят остальных, когда связь появится. Пакеты зашифрованы ключом
из кода кассы: без кода их не прочитать и не подделать. Внизу заголовка кассы видно, какие компьютеры
в сети и всё ли совпадает. Журнал — `cash.db` в папке данных.

## Linux

Linux-версия (Avalonia, пакет AppImage) — в папке [`OfficeChat.Linux`](OfficeChat.Linux/README.md).
Протокол общий: компьютеры на Windows и Linux переписываются друг с другом.

## Сервер и аккаунты

В офисе работает сервер ([OfficeChat.Server](OfficeChat.Server/README.md)): у каждого сотрудника аккаунт
(логин и пароль вводятся один раз), переписка общая на всех его устройствах. Программа находит сервер в
сети сама (или по адресу), при первом входе предлагает перенести переписку, которая велась на этом
компьютере без аккаунта. Без связи с сервером компьютеры переписываются напрямую, как раньше, а на
сервер всё уходит, когда связь появится.

На одном компьютере могут работать несколько аккаунтов (меню «Настройки ▾» → «Добавить аккаунт…»):
у каждого своя копия программы и своя папка данных. Можно и дальше работать без аккаунта — кнопка
«Работать без аккаунта» в окне входа.

## Сборка

Нужен .NET 10 SDK (только для сборки — пользователям он не нужен).

**Один exe для раздачи по офису** — запустите `OfficeChat.Windows\publish.cmd` или выполните:

```
dotnet publish OfficeChat.Windows/OfficeChat.Windows.csproj -p:PublishProfile=SingleExe
```

Получится `OfficeChat.Windows\bin\publish\OfficeChat.exe` (~75 МБ): .NET и все библиотеки уже внутри,
достаточно скопировать файл на компьютер и запустить. Нужна 64-битная Windows 10 или 11.

Для разработки откройте `OfficeChat.slnx` в Visual Studio или Rider.

## Автоматическая сборка (GitHub Actions)

Файл `.github/workflows/build.yml` собирает программу на серверах GitHub — ничего ставить не нужно:

- **каждый push** — на вкладке **Actions** откройте запуск «Сборка», внизу в **Artifacts** будут
  `OfficeChat-windows-x64` (exe) и, в ветке с Linux-версией, `OfficeChat-linux-x86_64` (AppImage);
- **выпуск для раздачи** — поставьте метку версии, и появится GitHub Release с обоими файлами:
  ```
  git tag v1.0.0
  git push origin v1.0.0
  ```
  (или на GitHub: **Releases → Draft a new release → Choose a tag → v1.0.0**);
- **вручную** — Actions → «Сборка» → **Run workflow**.

## Обновление по сети

Программы в офисе обновляются друг от друга: достаточно запустить новую версию на одном компьютере.
Остальные увидят её, скачают у него, проверят цифровую подпись и установят, когда окно свёрнуто в трей
(не посреди игры и не во время передачи файла). Обновлённая программа раздаёт версию дальше.

Подпись нужна, чтобы обновление нельзя было подделать: без верной подписи файл не принимается.
Подписывает только автоматическая сборка в GitHub Actions — для этого один раз добавьте в репозиторий
секрет **Settings → Secrets and variables → Actions → New repository secret**:
имя `UPDATE_SIGNING_KEY`, значение — закрытый ключ (PEM). Открытый ключ к нему записан в
`Services/UpdateService.cs`. Без секрета сборка работает как обычно, но по сети не обновляется
(в настройках программы будет написано «сборка без подписи»). Версия сборки — `1.1.<номер запуска>`.

Если программа лежит в папке, куда у пользователя нет прав на запись (например, `Program Files`),
обновиться она не сможет — держите `OfficeChat.exe` в папке пользователя.

## Сеть

Программа использует порты **UDP 45678** (поиск компьютеров), **TCP 45679** (сообщения)
и, в режиме «Касса», **UDP 45683** (общий журнал кассы).
Если на одном компьютере программу запускают несколько пользователей Windows, у второго и
следующих порты выбираются автоматически (свободные) — разрешение брандмауэра нужно дать программе целиком.
При первом запуске Windows спросит разрешение брандмауэра — разрешите доступ.
Если разрешение не дано (или сеть помечена как «Общественная»), к компьютеру не смогут подключиться:
в окне OfficeChat появится жёлтая плашка с кнопкой «Разрешить» — она добавит правило для всех типов сети
(Windows попросит права администратора).
Все компьютеры должны быть в одной подсети.

## Где лежат данные

`%AppData%\OfficeChat\` (в Linux — `~/.config/OfficeChat/`):
- `accounts.json` — аккаунты этого компьютера (ключ устройства зашифрован средствами Windows)
- `accounts\<Id>\` — данные аккаунта: те же `settings.json`, `history.db`, `images\`, `files\`, `stickers\`
- `settings.json` — имя и настройки (без аккаунта)
- `history.db` — история переписки (SQLite)
- `cash.db` — журнал кассы (режим «Касса»)
- `images\` — изображения из переписки (удаляются вместе с перепиской)
- `files\` — файлы из переписки (удаляются вместе с перепиской)
- `stickers\` — свои наборы стикеров (папка = набор)
- `logs\officechat-ГГГГ-ММ-ДД.log` — журнал работы (хранится 14 дней); при падении программа показывает путь к нему
