# OfficeChat

Локальный чат для офиса без сервера. Программа работает в фоне (в трее),
а новые сообщения всплывают в правом нижнем углу поверх всех окон.

## Возможности

- Компьютеры находят друг друга сами (UDP broadcast в локальной сети)
- Личные сообщения и рассылка «Всем» (раскладывается по личным перепискам)
- Очередь для тех, кто не в сети: сообщение уйдёт, когда компьютер появится; отправку можно отменить
- Отметки «Доставлено» и «Прочитано»
- Всплывающие уведомления с быстрым ответом
- Работа в трее, автозапуск вместе с Windows
- Вся история переписки хранится локально
- Мини-игра «Крестики-нолики» с собеседником: приглашение, принять/отклонить,
  поле прямо в переписке (панель справа), итог записывается в историю переписки

## Сборка

Нужен .NET 10 SDK (только для сборки — пользователям он не нужен).

**Один exe для раздачи по офису** — запустите `publish.cmd` или выполните:

```
dotnet publish -p:PublishProfile=SingleExe
```

Получится `bin\publish\OfficeChat.exe` (~75 МБ): .NET и все библиотеки уже внутри,
достаточно скопировать файл на компьютер и запустить. Нужна 64-битная Windows 10 или 11.

Для разработки откройте `OfficeChat.slnx` в Visual Studio.

## Сеть

Программа использует порты **UDP 45678** (поиск компьютеров) и **TCP 45679** (сообщения).
Если на одном компьютере программу запускают несколько пользователей Windows, у второго и
следующих порты выбираются автоматически (свободные) — разрешение брандмауэра нужно дать программе целиком.
При первом запуске Windows спросит разрешение брандмауэра — разрешите доступ для частной сети.
Все компьютеры должны быть в одной подсети.

## Где лежат данные

`%AppData%\OfficeChat\`:
- `settings.json` — имя и настройки
- `history.db` — история переписки (SQLite)
- `logs\officechat-ГГГГ-ММ-ДД.log` — журнал работы (хранится 14 дней); при падении программа показывает путь к нему
